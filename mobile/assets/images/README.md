# Recursos visuales

- `home-sculpture.png`: SVG proporcionado por el usuario para Inicio, rasterizado con transparencia a 2×. Se conserva la composición original de Inicio.
- `ribbon-sculpture.png`: mismo recurso, con márgenes transparentes recortados para las tarjetas decorativas.
- `orbit-sculpture.png`: segundo SVG proporcionado por el usuario (531 × 781), rasterizado y recortado por su canal alfa para las tarjetas de proyectos y entornos.
- `app-gradient-dark.svg` y `app-gradient-light.svg`: fuentes vectoriales de los fondos compartidos. Los PNG a 2× se usan en Android y web para evitar diferencias del degradado radial nativo.
- `demo/`: ilustraciones vectoriales del catálogo de ejemplo. Se conservaron los objetos y se adaptaron únicamente los fondos/sombras a la paleta oscura.

Los renders son imágenes decorativas; no representan un visor 3D interactivo ni resultados de reconstrucción.
